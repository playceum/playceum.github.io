FEATURES

なにが最新鋭？

Playceum のマインクラフト部門では、Minecraft: Java Edition を専用のクライアントから開きます。中身は、この 4 つ。

READY

押したら、もう整っている。

軽くする Mod、影、地図、建築の道具。みんなが入れているものが、はじめから入っています。遊び方をえらんで、押すだけ。

  • Mod の組み合わせ・設定・キーの割り当てまで用意ずみ
  • Java を自分で入れる手間なし
  • 自分で変えた設定は、上書きしません

LEARN

遊びながら、しくみが分かる。

学ぶためのゲームモードつき。ゲームの中で作ったものを取り込むと、読み取った結果が返ってきます。

  • レッドストーン: 回路を取り込むと、回路図と注意点が出る
  • 建築: 素材の割合・奥行き・照明を読み取る
  • Python: ゲームの中のエディタで書いて、動かす
  • サバイバル: 最初の夜からエリトラまで、つぎの一歩を案内
  • PvP: キー入力・CPS・防具の耐久が見える HUD

13 FIELDS

13 の分野を、行ったり来たり。

分野ごとに、図鑑・チュートリアル・研究。レッドストーンの論理回路から、プログラミングの論理演算へ。分野どうしがつながっています。

  • プレイ中に、キー 1 つで分野の本と Minecraft Wiki が開く
  • レッドストーンの図鑑は、NOT・AND・XOR・RS ラッチなどを回路図つきで

MULTI

友だちと、同じサーバーへ。

サーバーを立てると、参加コードができます。もらった人は、コードを入れるだけ。必要な Mod が自動でそろって、そのままつながります。

  • サバイバル・クリエイティブ・レッドストーン・PvP の型から立てられる
  • X-ray などの不正に当たる Mod は、入りません
